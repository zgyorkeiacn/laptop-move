Questions and answers

Who can use it?

Any Accenture employee, on a Windows laptop, with no administrator rights needed for the mover itself.

Is my password stored anywhere?

No. You type it into the page; it goes to 7-Zip through a pipe and is never stored, logged or put in a command line, a file or an address.

Where do I upload the bundle?

To your Accenture OneDrive only. Never a client's OneDrive, never a personal drive. The client part also only to your Accenture OneDrive.

What about client repositories?

With a remote: they stay out, you push first and clone again. Without a remote: a separate encrypted client part for your Accenture OneDrive only.

Are my passwords, keys and tokens moved?

No. They are listed on the by-hand list for you to set up again. Nothing is read from the Windows secret store.

Are printers and Wi-Fi moved?

No. Secure print queues come from the company setup on the new laptop: check that one page prints. No Wi-Fi profile or key is packed: check that the office network is there.

Does it change my repositories?

No. It does not push or fetch, and it reads git without locks.

Does it change anything on the old laptop?

It writes only the bundle folder you name, and your selection file if you save it (the old one is kept as a .bak.json copy). Nothing is deleted or changed on the old laptop.

Can I try it first?

Yes. The dry run changes nothing, and --target-root restores into a trial folder instead of the real places.

Can I move only some things?

Yes. You choose folders, repositories, applications and settings. Save the selection and load it later.

How long does it take?

The dry run gives an estimate. Most of the time is waiting for the upload and download.

Why are some files left out?

Folders that can be rebuilt (node_modules, build output, caches) are skipped to keep the bundle small. Secret-bearing files are left out on purpose.

What if the restore stops half way?

Run it again. It continues where it stopped, and keeps files that already exist.

Can I use another place, such as a USB stick?

The guide supports Accenture OneDrive only.

Who can I ask?

Your IT support, with the report in hand. IT can read the security page.
