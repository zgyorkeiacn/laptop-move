The dry run

The dry run writes nothing. It shows the size of the bundle, the number of parts, the time to pack, upload and unpack, and the route of every application.

  • The output folder must be on a local drive, not in a OneDrive folder: you upload the files yourself.
  • Fix any problem it lists, then run it again.
  • Client repositories with local work that is not pushed are listed under "Push first".
