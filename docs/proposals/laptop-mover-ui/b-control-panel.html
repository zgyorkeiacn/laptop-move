Laptop moverTutorial

Tutorial: your first move in 5 steps

  1. Scan. The mover lists folders, applications, settings and repositories. Nothing is changed.
  2. Choose. Tick what moves. Client repositories with a remote stay out.
  3. Pack. Type a password when 7-Zip asks. Keep it safe: it is not stored.
  4. Upload. Put the bundle on your Accenture OneDrive yourself.
  5. Restore. On the new laptop download the bundle and run one command.
Tip: run the dry run first. It shows size, parts, time and the route of every app.

Laptop moverInstructions

Detailed instructions: restore on the new laptop

  1. Download the kit zip and all data parts into one new folder, for example C:\move.
  2. Unzip laptop-move-kit.zip there. It holds the mover, the manifest, a README and the signed node.exe.
  3. Open PowerShell in that folder and run the one command shown below. Do not change the execution policy.
  4. Type the password when 7-Zip asks, once per archive.
  5. Read the report. Do the by-hand list. Clone the client repositories after you push them.
.\node.exe kit\kit.mjs restore --bundle C:\move
If a checksum failsDownload that part again. Never unpack a part that failed its check.
If an app install is refusedThe signature did not match the recorded publisher. Install that app from the vendor's own page.

Help

Context help for the section you are in.

Is my password stored anywhere?No. 7-Zip asks for it at its own prompt. The mover never sees, stores or logs it.
Where do I upload the bundle?To your Accenture OneDrive only. Never a client's OneDrive.
What about client repositories?With a remote: they stay out, you push first and clone again. Without a remote: a separate encrypted client part for Accenture OneDrive only.
Does it change my repositories?No. It does not push or fetch and reads git without locks.
