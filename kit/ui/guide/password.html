Old laptop, step 5: the password

Every part is encrypted with 7-Zip AES-256, file names too. You choose one password for all parts.

  1. Type a long passphrase in both fields. It must have at least 12 characters, and only letters, digits, spaces and the signs of a US keyboard, so it types the same on any keyboard (no accented letters).
  2. The three rules under the fields turn green when they hold. Pack now stays grey until they all do.
  3. Write the password down somewhere safe, away from the bundle (your approved password manager is the right place). Nobody can recover it.
Never put the password in the bundle folder, in an email or on OneDrive. The mover sends it from the page to 7-Zip through a pipe: it is never in a file, a log, a command line or an address, and the mover keeps no copy.
