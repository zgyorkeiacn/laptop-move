Restore on the new laptop

  1. Download the kit zip and all parts into one new folder, for example C:\move.
  2. Unzip laptop-move-kit.zip there.
  3. Open PowerShell in the unzipped kit folder and run .\node.exe kit.mjs ui. Do not change the execution policy.
  4. In the page, check the bundle first: nothing is written. Then type the password and restore.

Without a page: .\node.exe kit.mjs restore --from C:\move. 7-Zip then asks for the password in the console.

The restore checks every part's checksum before it unpacks anything, installs applications only when their signature is valid, and keeps a copy of any file it replaces when you ask it to overwrite.
