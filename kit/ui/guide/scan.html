Old laptop, step 1: scan

The scan only reads. It lists folders, applications, settings and repositories so you can choose what moves. It never pushes, fetches or locks a repository, and it never shows a remote's address.

  1. Start the page with node kit.mjs ui (see Getting started).
  2. If you saved a selection earlier, Load it on the start page: the scan is then optional. Otherwise press Start: scan this laptop.
  3. Leave Where to look empty to scan your user folder and the system drive, or give one folder per line.
  4. Keep Ask winget which applications are installed ticked to get the application list. It takes a minute.
  5. Press Scan now and wait for the status to read done.
You can stop and come back: the page keeps the scan result until you press End.
