Old laptop, step 2: choose what moves

Four screens, one for each kind of thing. On each, tick what moves; the line under the table counts your choices. Every row says what will happen to it on the new laptop.

Folders

A folder is copied whole to the same path on the new laptop. Folders that hold secrets are never copied: they go on the by-hand list. Sizes come with the dry run.

Repositories

A repository with a remote is cloned again, with your local commits, stashes and uncommitted files put back. A client repository with a remote stays out of the bundle: push it first. One without a remote goes into the separate client part.

Applications

Each application shows how it will be installed: winget, a signed vendor download, or Software Center. Software Center and Company Portal apps are only listed: install them there. A vendor installer on the new laptop is run only when its signature is valid and matches the recorded publisher.

Settings

Tick the settings you want carried. Two things are not moved at all and are shown on this screen as checks for the new laptop: printers (secure print queues) and Wi-Fi (no profile or key is packed).
