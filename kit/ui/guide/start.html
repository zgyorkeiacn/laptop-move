Start

The laptop mover helps you move your work from an old laptop to a new one in four parts: scan and choose, dry run and pack, upload, restore and check. It runs on your own computer only, in a page at 127.0.0.1, and it uploads nothing.

  1. On the old laptop, open PowerShell in the mover's folder and run node kit.mjs ui. The page opens in your browser.
  2. Load the selection you saved earlier, or scan this laptop and choose what moves.
  3. Run the dry run, then pack with a password you type twice.
  4. Upload the files to your Accenture OneDrive yourself.
  5. On the new laptop, unzip the kit, run .\node.exe kit.mjs ui and restore.
