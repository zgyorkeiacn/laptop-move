Old laptop, step 3: the by-hand list

These items are never copied. For each one, move it the safe way for what it is, or create it again on the new laptop, then tick it. The ticks stay in the page only.

  1. Read the list. It holds the secret folders and files in your selection, the printer check and the Wi-Fi check.
  2. Run the dry run (next page) to add the secret-bearing files it finds inside your chosen folders.
  3. Under Save the selection, give a full path ending in .json and press Save the selection. An existing file is kept as a dated .bak.json copy. The page never saves into a client's folder or a OneDrive folder.
Never copy these files into the bundle yourself, and never send them by email or chat. Keep your own list for the new laptop.
