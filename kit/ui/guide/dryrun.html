Old laptop, step 4: the dry run

The dry run shows what packing would do. Nothing is written.

  1. Give an output folder on a local drive, for example C:\LaptopMove\bundle. It must be new or empty, and not inside a OneDrive folder: you upload the files yourself.
  2. Leave part size empty for 4 GB parts, or give a size such as 500m.
  3. Tick Carry client repositories whole only if your lead asks for it. They still go only into the separate client part.
  4. Press Run the dry run and wait for finished: ready to pack.
