Troubleshooting

A checksum fails

The page says a part is damaged or its SHA-256 does not match. A part was not downloaded completely or was changed.

  1. Download that part again from OneDrive, and compare its size with the one on OneDrive.
  2. Run Check first again.

Never unpack a part that failed its check. If it fails again, the file on OneDrive may be incomplete: upload that part again from the old laptop.

An application will not install

  • Refused for its signature: the installer's signature is not valid or does not match the recorded publisher. This is on purpose. Install that application from the vendor's own page or from Software Center.
  • Software Center apps: these are only listed. Open Software Center and install them there.
  • Anything else: run the restore again (it continues where it stopped), or run only the installs with .\node.exe kit.mjs apps. You can also skip the applications and install them later.

winget is missing

winget comes with App Installer. Open the Microsoft Store (or Software Center), install or update App Installer, open a new PowerShell window, and run winget --version. If it prints a version, run the restore again. Applications with a signed vendor download are installed without winget; the others are listed for you to install by hand.

7-Zip says the password is wrong

Type it again with care for capital letters and spaces. On the console 7-Zip lets you try three times. The same message can mean a damaged part: check the checksums first. The password cannot be recovered; without it the bundle cannot be opened.

Not enough space

  • Old laptop: choose an output folder on a drive with more room, or untick large folders.
  • New laptop: the check names the drive and the room needed (about 1.3 times the bundle size). Free some space or choose another work folder on a bigger local drive, then check again.

The page says the mover has ended

The mover stops when you close its page, or press End the mover. Run node kit.mjs ui (or .\node.exe kit.mjs ui) again for a new page.

The page will not open, or says it needs the link

The link works once. Close the old tab and start the mover again, or use --no-open and paste the printed link into your browser.

The output folder is refused

It is inside a OneDrive folder or a client folder. Pick a plain local folder such as C:\LaptopMove\bundle.

A repository did not clone

Sign in when Git Credential Manager asks, and check you are on the right network or VPN. Run the restore again; repositories already cloned are kept.

Still stuck? Keep the report and the text of the error and ask your IT support. Never send the password or the bundle.
