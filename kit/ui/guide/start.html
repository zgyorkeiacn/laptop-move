Getting started

The laptop mover helps you carry your own work from an old laptop to a new one. It reads what you choose, packs it into encrypted parts, and, on the new laptop, puts everything back where it was and writes a report of what is left for you to do. It runs on your own computer only, in a page at 127.0.0.1, and it uploads nothing: you do the upload yourself.

It is for any Accenture employee. You need Windows 11, a Command Prompt or PowerShell window, and about an hour of your time, most of it waiting.

What the mover moves

  • Folders you tick: copied whole, to the same path on the new laptop, minus folders that can be rebuilt (node_modules, build output, caches, .temp).
  • Git repositories: cloned again from their remote on the new laptop. Your unpushed commits and stashes travel as a git bundle, and your uncommitted files are copied. A repository with no remote is copied whole.
  • Applications: installed again on the new laptop, one by one, with winget or a signed vendor installer. Software Center apps are listed for you to install there.
  • Settings you tick: editor extensions, global npm packages and the settings files of the apps you chose.
  • Junctions: recreated.

What the mover never moves

  • Secrets. Files such as .env, .npmrc, SSH keys, certificates, cloud credentials, tokens and browser logins are never copied, even if you ticked their folder. They are listed on the by-hand list for you to set up again yourself.
  • Credentials stored by Windows (Credential Manager, the Windows secret store) and saved Wi-Fi keys.
  • Printers. Secure print queues (Pharos Secure Print) come from the company setup on the new laptop: you check that one page prints.
  • Client repositories that have a remote. They stay out of the bundle: you push, then clone again.

The four parts

  1. Scan and choose on the old laptop. Nothing is changed.
  2. Dry run and pack: see size and time first, then pack with a password you type twice.
  3. Upload the bundle to your Accenture OneDrive, and download it on the new laptop.
  4. Restore and check on the new laptop: one page, then a report.

Start the mover

On the old laptop, open PowerShell in the kit folder of the mover and run:

node kit.mjs ui

The page opens in your default browser through a one-time link. The mover stops when you close the page, press End the mover. Use --no-open to have the link printed instead of opened.
