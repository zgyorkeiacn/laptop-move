Old laptop, step 6: pack

  1. On the password page press Pack now. The page moves to Packing progress.
  2. Wait. The steps (settings, bundles of local commits, file lists, 7-Zip, checksums, the kit zip) turn done one by one, and each part has its own bar.
  3. When the green box says Packed, press Open the folder to see the bundle.

What is in the bundle folder

FileWhat it is
data-*.7z.001, .002, ...The encrypted data parts.
client-*.7z.*The separate encrypted client part, if there is one. Accenture OneDrive only.
laptop-move-kit.zipThe mover, the manifest, a README and the signed node.exe. Not encrypted: it holds no data.
SHA256SUMS.txt, manifest.jsonChecksums and the list of what is inside.

Do not rename, split or delete any of these files. You can close the page now; the mover stops when it is closed.
