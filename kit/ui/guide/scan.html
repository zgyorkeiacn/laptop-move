Scan this laptop

The scan lists the folders, repositories, applications and settings it finds. It only reads: it never pushes, fetches or locks a repository, and it shows no remote's address.

  • Leave "Where to look" empty to scan your user folder and the system drive, or name the folders to scan.
  • Asking winget for the installed applications takes about a minute.
  • Folders that look like they hold secrets are marked and go on the by-hand list.
