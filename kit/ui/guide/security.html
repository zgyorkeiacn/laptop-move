Security notes for IT

QuestionAnswer
Encryption7-Zip AES-256, file names encrypted. The password is typed by the user, piped to 7-Zip and never stored.
IntegritySHA-256 per part, checked before anything is unpacked.
ExecutablesOnly the official signed portable node.exe, the installed 7-Zip 26.03 or newer, and winget. Vendor downloads run only if the Authenticode signature is valid and matches the recorded publisher.
NetworkThe page is served on 127.0.0.1 only, on a free port, behind a one-time link, a session cookie and a per-page key. Requests from another site or another host name are refused. The tool uploads nothing.
SecretsNever copied; listed for by-hand moving. No Wi-Fi profile or key is exported.
Client dataClient repositories with a remote stay out; others go into a separate encrypted part for Accenture OneDrive only. The mover never writes into a client's OneDrive.
Credential storesNone used.
