The password

Every part is encrypted with 7-Zip (AES-256, file names too).

  • Use at least 12 characters: letters, digits, spaces and the signs of a US keyboard, so it types the same on any keyboard.
  • Type it twice in the page. It goes from the page straight to 7-Zip through a pipe: it is never on a command line, in a file, in a log or in an address, and the mover keeps no copy.
  • Write it down somewhere safe. Without it the bundle cannot be opened, and nobody can recover it.
